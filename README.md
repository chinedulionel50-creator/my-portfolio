# Uzoho Chinedum Miracle — Portfolio Website

A responsive dark-themed portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content
- `style.css` — layout, colours, and responsive styling
- `script.js` — mobile menu and current footer year

## Run locally
Open `index.html` in your browser. No build tools are required.

## Before publishing
1. Replace `your.email@example.com` in `index.html` with your real email address.
2. Replace the GitHub link with your GitHub profile URL.
3. Update skills to match what you actually know.
4. Add links to your real projects and update their descriptions.
5. Add your CV only if you want to make it public.

## Publish with GitHub Pages
1. Create a repository on GitHub (for example, `my-portfolio`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open the repository's **Settings** → **Pages**.
4. Under the build/deployment source, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site; the Pages screen will show the live address.
